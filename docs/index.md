# Discord Unlocked

Discord Unlocked is a self-hosted Windows Vencord userplugin with a Discord bot, authenticated API and moderated profile editor. It is intended for a small community, with at most 50 enrolled accounts. It is not an official Discord or Vencord plugin.

The planned company/brand name is **Boronen Games**; the current operator remains an individual. The profile editor/plugin still appears as **Profile Studio** in existing clients. Existing identifiers, local settings, VM service paths and commands are retained for compatibility.

**Local refactor candidate:** source features and automated checks exist; a browser preview is not proof of native Discord compatibility or production readiness. The current release gates are listed in [Acceptance](ACCEPTANCE.md) and the [development record](DEVELOPMENT-RECORD.md). No public repository or live deployment is created by building these docs.
